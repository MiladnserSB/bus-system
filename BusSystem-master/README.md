# Masar Bus Management Dashboard — لوحة تحكم مسار

لوحة إدارة العمليات ومكتب الاستقبال لشركة مسار للنقل البري بين المحافظات، مبنية باستخدام **Next.js 15 (App Router)**، **TypeScript (Strict)**، و**Tailwind CSS v4**، ومرتبطة بالكامل بواجهة البرمجة الخلفية NestJS (`/api/v1`).

## الهوية البصرية والمعايير الموحدة (SRS 3.1.1)
- **اللون الأساسي (Primary Deep Blue):** `#133883` (`#0D275C` للضغط، `#EBF1FC` للخلفيات الخفيفة).
- **اللون الثانوي (Accent Amber):** `#E0A100` (`#FEF6E0` للتمييز والمقاعد الإضافية `9E`/`11E`).
- **الاتجاه والخط والتنسيق:** عربي كامل من اليمين إلى اليسار (`dir="rtl"`) مع أرقام غربية (`0-9`)، توقيت دمشق بصيغة 24 ساعة (`Asia/Damascus`)، وتنسيق عملة موحد (`45,000 ل.س`).
- **مخطط الباصات:** اتجاه فيزيائي ثابت للمقصورة (`dir="ltr"`) متطابق مع تطبيق الهاتف لجميع أنواع الباصات الستة (`2+2`, `2+1`, `1+1`)، مع إشعارات `5000ms` وأيقونات حالة واضحة (`✓` للمحدد، `×` للمحجوز، أيقونة ساعة وحدود متقطعة للمقعد المثبت مؤقتاً).

## الصفحات والصلاحيات (RBAC)
- **المصادقة والحساب (`/login`, `/change-password`, `/profile`):** تسجيل دخول الموظفين عبر JWT + Refresh Token، تجميد الحساب بعد 5 محاولات فاشلة، وفرض تغيير كلمة المرور المؤقتة (`mustChangePassword`).
- **المدير وموظف الاستقبال (`/`, `/trips`, `/trips/[id]`, `/bookings`):** استعراض الرحلات، خريطة المقاعد التفاعلية مع تحديث تلقائي كل 10 ثوانٍ وتثبيت مؤقت 5 دقائق، حجز فوري مع `Idempotency-Key`، طباعة التذاكر (`A5` و`80mm` الحراري مع QR)، طباعة كشف الركاب، تعديل بيانات الركاب، وإلغاء الحجوزات والمقاعد.
- **المدير العام فقط (`/scheduled-trips`, `/stations`, `/fleet`, `/analytics`, `/staff`, `/audit`, `/settings`):** إدارة القوالب الدورية ومعاينة المواعيد والاستثناءات، المحطات، أنواع الباصات مع معاينة هندسية مباشرة، الأسطول، التقارير مع التصدير (`CSV` / `PDF`)، حسابات الموظفين، سجل التدقيق، والسياسات السبع للنظام.

## الإعداد والتشغيل والتحقق
```bash
cp .env.example .env
# تأكد من تعيين NEXT_PUBLIC_API_URL=http://localhost:3000/api/v1

npm install
npm run typecheck
npm run lint
npm test
npm run build
```
